How to use this guide

  • →Work through one chapter at a time. Read the question, answer it out loud, then compare with the written answer.
  • →Say the Key learning line from memory. If you cannot, re-read the answer.
  • →Run the T-SQL examples in a test instance. Interview answers land better when you have typed the query.
  • →For scenario questions, practice leading with the first diagnostic step before any detail.
  • →The diagrams are the ones to sketch on a whiteboard: B-tree, clustered vs nonclustered, plan flow, histogram, WAL, isolation levels, AG topology, Query Store, buffer pool IO path, deadlock cycle, partitioning, the tempdb version store, joins Venn, aggregate vs window, the backup chain, database/schema containment, the PK/FK link, parameter sniffing, FCI vs AG, and partition elimination — plus three animations (B-tree search, deadlock cycle, CTE flow).
